# Parable Topics — Handoff for Claude Code

## Context

This document extends the parable generator for the **Study Go Together** YouTube channel.

The generator already has 5 approved parables (`parable_001` through `parable_005`).
All five share the same core message: *stop preparing, start speaking, mistakes are fine.*

This is a problem. Viewers predict the ending by screen 5.

This handoff adds **20 new topic seeds** with deliberately different angles — different emotions, different audiences, different final lessons.

-----

## Your Task

Add these topics to your parable generation skill/rotation pool.

When generating a new parable:

1. Pick a topic from this list (rotate, do not repeat consecutively)
1. Check that the final lesson (screen 8) is **different** from the existing five parables
1. The existing five all end with a variation of “speak before you’re ready” — avoid this

## Generation Rules

These apply on top of existing parable generation rules:

- **Screen 8 is the only place for the lesson** — never on screen 7 or earlier
- **No two consecutive parables from the same category** — rotate across Identity / Middle / Connection / Time / Fear / Provocation
- **The lesson must be a reframe, not a command** — “you are not just learning words” not “go speak now”
- **Specific detail over abstraction** — “she had friends in four countries” not “she succeeded”
- **Leave some things unresolved** — especially T12, T19, T20. Not every parable needs a happy ending.
